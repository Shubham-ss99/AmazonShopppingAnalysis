Amazon E-Commerce Sales & Customer Feedback Analysis📌 

Project OverviewThis project delivers a robust Power BI Interactive Dashboard designed to analyze Amazon e-commerce data. By synthesizing financial performance, inventory movement, and customer sentiment metrics, this analysis transforms raw transactional data into actionable business intelligence.The primary objective is to empower stakeholders to track top-line revenue metrics, monitor product velocity, evaluate customer satisfaction, and isolate seasonal trends to optimize inventory management and marketing campaigns.🚀 Key Features & Analysis DimensionsTime-Intelligence Monitoring: Tracks dynamic financial performance across strict corporate timelines (Year-to-Date and Quarter-to-Date).Granular Trend Analysis: Deconstructs sales performance down to monthly macro-seasons and weekly operational fluctuations.Product Performance Mapping: Identifies core revenue engines and top consumer-rated inventory items.Customer Feedback Tracking: Integrates textual volume metrics to proxy user satisfaction and engagement.📊 Data Model & Star Schema ArchitectureThe dashboard relies on a highly optimized Star Schema data architecture to ensure rapid visual rendering and strict cross-filtering capabilities.Fact Table: Amazon_Data (Stores numerical metrics: Price, Number of Reviews, Transaction Dates, Product Category, and Individual Product Keys).Dimension Table: Date Table (A comprehensive calendar table detailing Year, Quarter, Month, Week, and exact Date values).Relationship: A strict 1-to-Many (1:*) one-way relationship from 'Date Table'[Date] to 'Amazon_Data'[Transaction_Date].🛠️ DAX Measures DirectoryThe analytical engine utilizes the following precise Data Analysis Expressions (DAX) formulas to generate baseline figures:1. Year-to-Date (YTD) RevenueCaptures the accumulation of financial revenue from the beginning of the current calendar year.DAXYTD Sales = TOTALYTD(SUM(Amazon_Data[Price(Dollar)]), 'Date Table'[Date])
Use code with caution.2. Quarter-to-Date (QTD) RevenueIsolates financial performance metrics within the current active quarter to monitor short-term fiscal objectives.DAXQTD Sales = TOTALQTD(SUM(Amazon_Data[Price(Dollar)]), 'Date Table'[Date])


Use code with caution.3. Year-to-Date Inventory MovementCounts the gross volume of items moving through the logistics pipeline by tracking processed product rows.DAXYTD Products Sold = TOTALYTD(COUNT(Amazon_Data[Product Category]), 'Date Table'[Date])


Use code with caution.4. Year-to-Date Customer Review EngagementAggregates total customer feedback volume to track customer engagement.DAXYTD Reviews = TOTALYTD(SUM(Amazon_Data[Number of reviews]), 'Date Table'[Date])


Use code with caution.📈 Dashboard Layout & Visual RequirementsThe reporting user interface is organized systematically to guide a viewer from high-level summaries down to precise root-cause analysis:1. Executive KPI Summary Cards (Top Row)YTD Sales Card: Highlights gross top-line revenue.QTD Sales Card: Monitors active quarterly pacing.YTD Products Sold Card: Gauges shipping and warehousing scale.YTD Reviews Card: Acts as the primary operational satisfaction index.2. Temporal Trend Grid (Middle Section)Sales by Month (Line Chart): Built to track high-level historical seasonality, peaks, and year-over-year revenue valleys.Sales by Week (Column Chart): Built to flag sudden micro-fluctuations driven by flash promotions or supply chain delays.3. Strategic Product & Category Grid (Bottom Section)Sales by Product Category (Heat Map Matrix): Provides a visual matrix layout evaluating product category performance.Top 5 Products by YTD Sales (Horizontal Bar Chart): Filters the top 5 distinct items generating the highest absolute revenue.Top 5 Products by YTD Reviews (Horizontal Bar Chart): Identifies the top 5 consumer-favorite items based on raw review numbers.💡 Key Business Insights GeneratedSeasonality Mapping: Comparing monthly line curves reveals explicit annual spikes, optimizing seasonal budget allocations.Core Revenue Contributors: The Top 5 Revenue vs. Top 5 Reviews charts show whether high-volume sales are driven by high satisfaction or purely aggressive marketing.Operational Velocity: Tracking weekly transaction counts allows logistics managers to appropriately scale fulfillment center staffing levels.
